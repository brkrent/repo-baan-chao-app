# บ้านเช่า — เวอร์ชันเชื่อมต่อ Supabase จริง

โปรเจกต์นี้ต่อกับฐานข้อมูล Supabase ที่ตั้งไว้แล้ว (URL และ anon key ใส่ไว้ให้ใน
`src/supabaseClient.js` เรียบร้อย ไม่ต้องแก้อะไรเพิ่ม)

## สิ่งที่ต้องมีก่อนเริ่ม

- ติดตั้ง [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป (โหลดตัวติดตั้งแล้วกด Next ไปเรื่อยๆ)
- รันสคริปต์ฐานข้อมูลให้ครบ **2 ไฟล์** ใน Supabase SQL Editor ตามลำดับ:
  1. `rental-app-schema.sql` (ไฟล์เดิมที่เคยรันไปแล้ว — ถ้ารันแล้วข้ามได้)
  2. `rental-app-schema-addon.sql` (ไฟล์ใหม่ในโปรเจกต์นี้ — ต้องรันเพิ่ม)

## รันดูบนเครื่องตัวเอง

เปิด Terminal / Command Prompt ไปที่โฟลเดอร์นี้ แล้วพิมพ์:

```
npm install
npm run dev
```

จะได้ลิงก์ประมาณ `http://localhost:5173` เปิดในเบราว์เซอร์เพื่อทดสอบ

## การสร้างผู้ใช้ (เจ้าของบ้าน / ผู้เช่า)

แอปนี้ใช้ระบบ login จริงของ Supabase แต่ปรับให้ผู้ใช้พิมพ์แค่ **"รหัส ID"** สั้นๆ
(เช่น `landlord` หรือ `1a`) แทนอีเมลจริง — เบื้องหลังระบบจะแปลง ID เป็นอีเมลปลอม
รูปแบบ `<id>@baanchao.local` ให้อัตโนมัติ (ไม่ต้องมีอีเมลจริง ไม่มีใครส่งเมลไปถึง
จริงๆ เพราะ Supabase ไม่ตรวจสอบว่าโดเมนนี้มีอยู่จริงไหม) ต้องสร้างบัญชีผ่าน
Dashboard ก่อนใช้งาน:

1. ไปที่ **Authentication → Users → Add user** ในช่อง Email ให้พิมพ์
   `<id>@baanchao.local` เช่น เจ้าของบ้านพิมพ์ `landlord@baanchao.local`,
   ผู้เช่าห้อง 1A พิมพ์ `1a@baanchao.local` — ตั้งรหัสผ่านแยกกัน แล้วกด Create
   (อย่าลืมเปิด **Auto Confirm User** ทุกครั้ง)
2. คัดลอก **User UID** ที่ระบบสร้างให้ (คอลัมน์ UID ในตาราง)
3. ไปที่ **Table Editor → profiles → Insert row** ใส่:
   - `id` = UID ที่คัดลอกมา
   - `role` = `landlord` หรือ `tenant`
   - `full_name` = ชื่อที่จะแสดงในแอป
4. ถ้าเป็นผู้เช่า: หลังจากสร้าง room ในแอป (ปุ่ม "เพิ่มห้อง") จะมีช่องให้ใส่
   "Tenant User ID" — ใส่ UID เดียวกับข้อ 2 เพื่อผูกห้องกับผู้เช่าคนนี้

> อย่างน้อยต้องมีบัญชี **เจ้าของบ้าน 1 คน** ก่อน ถึงจะเข้าไปกดเพิ่มห้อง/ผู้เช่าต่อได้

## Deploy ขึ้นเป็นเว็บใช้งานจริง (ฟรี ผ่าน Vercel)

1. สมัครบัญชีที่ [vercel.com](https://vercel.com) (ใช้ GitHub login ได้)
2. อัปโหลดโค้ดโฟลเดอร์นี้ขึ้น GitHub (สร้าง repo ใหม่ แล้วลากไฟล์ทั้งหมดขึ้นผ่านหน้าเว็บ
   GitHub ก็ได้ ไม่ต้องใช้คำสั่ง git ก็ได้ถ้าไม่ถนัด)
3. ใน Vercel กด **New Project** เลือก repo ที่อัปโหลดไว้ ปล่อยค่าเริ่มต้นทั้งหมด
   (Vercel จะรู้เองว่าเป็นโปรเจกต์ Vite) กด **Deploy**
4. รอ 1-2 นาที จะได้ลิงก์เว็บจริง เช่น `https://baan-chao-app.vercel.app`
   ที่ใครก็เข้าได้จากมือถือ/คอมทุกเครื่อง

## ข้อจำกัดที่ยังเหลืออยู่ (สำคัญ ต้องรู้ก่อนใช้กับเงินจริง)

- **การชำระเงิน (พร้อมเพย์/บัตร) ยังเป็นแค่ตัวจำลอง** — กดแล้วระบบจะเปลี่ยนสถานะ
  เป็น "ชำระแล้ว" ทันทีโดยไม่มีการตัดเงินจริง ถ้าจะรับเงินจริงต้องสมัคร payment
  gateway (Omise, 2C2P, Beam ฯลฯ) แล้วเขียน Edge Function เชื่อมต่อ — บอกได้เลย
  ถ้าอยากให้ช่วยขั้นตอนนี้ต่อ
- **การสร้างบัญชีผู้เช่ายังต้องทำผ่าน Supabase Dashboard เอง** (ไม่มีปุ่ม
  "สมัครสมาชิก" ในแอป) เพราะการสร้างบัญชีผู้ใช้ใหม่ต้องทำผ่านเซิร์ฟเวอร์ที่
  ปลอดภัยเท่านั้น — ถ้าต้องการให้เจ้าของบ้านเพิ่มผู้เช่าได้เองในแอปแบบไม่ต้อง
  สลับไปมา ต้องเพิ่ม Edge Function อีกตัวหนึ่ง (ทำเพิ่มได้ทีหลัง)
- ฟอนต์/สไตล์โหลดผ่าน Tailwind CDN เพื่อความง่าย เหมาะกับใช้งานจริงระดับเล็ก-กลาง
  ถ้าจะขยายใหญ่ในอนาคตค่อยเปลี่ยนเป็นการติดตั้ง Tailwind แบบเต็มรูปแบบ
